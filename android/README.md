# PhishGuard for Android

Native wrapper around the same URL + HTML checks as the Windows app.

- `applicationId`: `com.phishguard.scanner`
- minSdk 26 (Android 8)
- Fetches HTML from the device (INTERNET). No PhishGuard server.

Build:

```bash
./gradlew assembleDebug
```

Play upload: see `docs/play-store.md`.
