NetWatch

Local network sentinel

Watches this computer for incoming pings and for local man-in-the-middle signs: a changed router MAC, that same MAC on another address, and ICMP redirects. It does not read the pages you open and it does not send anything onto the network. The desktop window is the application. This page is only the optional local view.

Limits

      
This is not a file antivirus. It cannot see an attack at your provider, or a fake Wi-Fi that is itself the router. Without administrator rights it can see that pings arrived, not who sent them. Pinning applies only to the confirmed router MAC on this computer.
